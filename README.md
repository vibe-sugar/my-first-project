# 🧮 계산기 프로그램 (GUI Calculator)

실제 계산기처럼 클릭 가능한 GUI 기반 Python 계산기 프로그램입니다.  
상단에 수식과 현재 계산값이 실시간으로 표시되며, 키보드 입력도 지원합니다.

---

## 📋 주요 기능

| 기능 | 설명 |
|------|------|
| 사칙연산 | 덧셈(+), 뺄셈(-), 곱셈(×), 나눗셈(÷) |
| 소수점 계산 | 소수 입력 및 연산 지원 |
| 퍼센트 (%) | 현재 값을 100으로 나눠 퍼센트 변환 |
| 부호 전환 (+/-) | 양수 ↔ 음수 전환 |
| 연속 계산 | `=` 없이 연산자 연속 입력 가능 |
| 수식 표시 | 상단에 진행 중인 수식 실시간 표시 |
| 동적 폰트 | 숫자 길이에 따라 폰트 크기 자동 조절 |
| 천 단위 쉼표 | 큰 숫자에 자동 쉼표 추가 |
| 키보드 지원 | 숫자, 연산자, Enter, Backspace, Esc 키 |
| 로그 기록 | 모든 계산 과정을 log.txt에 저장 |

## 🚀 설치 방법

### 1. Python 설치 확인
```bash
python --version   # Python 3.12.x 권장
```

### 2. 가상환경 생성 및 활성화 (권장)
```bash
# 가상환경 생성
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3. 외부 의존성
이 프로그램은 **Python 표준 라이브러리만 사용**하므로 별도 패키지 설치가 필요 없습니다.

- `tkinter` — GUI (Python 내장)
- `decimal` — 정밀 연산 (Python 내장)
- `logging` — 로그 기록 (Python 내장)

> ⚠️ Linux 환경에서 tkinter가 없는 경우:
> ```bash
> sudo apt-get install python3-tk
> ```

## ⌨️ 키보드 단축키

| 키 | 기능 |
|----|------|
| `0` ~ `9` | 숫자 입력 |
| `+` `-` `*` `/` | 연산자 입력 (곱셈: `*`, 나눗셈: `/`) |
| `Enter` / `=` | 결과 계산 |
| `.` | 소수점 입력 |
| `%` | 퍼센트 변환 |
| `Backspace` | 마지막 입력 삭제 |
| `Esc` / `C` | 전체 초기화 (AC) |

## 📊 사용 예시

### 기본 계산
```
123 + 456 = → 579
10 ÷ 3    = → 3.333333333333333
```

### 연속 계산
```
5 + 3 × 2 = → (5+3) 먼저 계산 후 ×2 = 16
```

```

```

```
42 → +/- → -42
```

## ⚠️ 주의사항

- **0으로 나누기**: `오류` 표시 후 AC로 초기화하세요.
- **최대 입력 자릿수**: 정수부 기준 15자리까지 입력 가능합니다.
- **GUI 환경 필요**: 디스플레이(모니터)가 연결된 환경에서만 실행 가능합니다.
- **tkinter 설치**: Linux 일부 환경에서 별도 설치가 필요할 수 있습니다.

## ❓ FAQ

**Q. 창이 열리지 않습니다.**  
A. `python3-tk` 패키지가 설치되어 있는지 확인하세요.  
Linux: `sudo apt-get install python3-tk`

**Q. 계산 기록을 확인하고 싶습니다.**  
A. 프로젝트 루트의 `log.txt` 파일을 열어보세요. 모든 계산 과정이 타임스탬프와 함께 기록되어 있습니다.

**Q. 소수점 이하 자릿수가 너무 많아요.**  
A. `decimal` 모듈을 사용하여 최대 28자리 정밀도로 계산됩니다. 결과값의 불필요한 0은 자동으로 제거됩니다.
